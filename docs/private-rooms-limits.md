# 닫힌 방 — 되는 것 / 불가능한 것

낙서(일기)와 복불복 전용 방. 자리 둘: **나**, **그양반**. 에이전트는 본문을 쓰지 않는다.

주소: `/rooms` · `/rooms/diary` · `/rooms/bokbulbok`  
로컬 기본: `http://127.0.0.1:3001/rooms`

공개 메뉴·헬스 페이지·사이트맵에 없음. 구글 메일·문자앱을 쓰지 않는다.

## 되는 것 (노력)

- 같은 자리 암호로 어느 기기에서 이 호스트에 들어가면, 그 컴퓨터에서 같은 글이 바로 열린다.
- Gmail / SMS / Google 로그인을 열지 않음. 그 앱 읽음·검색·동기화 흔적은 이 방이 만들지 않음.
- 디스크에는 암호문만. `data/private-rooms/` 는 gitignore.
- robots / noindex / no-referrer / no-store.
- 50/50 ACL: owner + em 만 세션을 받을 수 있음.

## 불가능한 것

- 흔적 0. 주소창 기록, 쿠키, 키보드/IME, 화면, OS 스왑은 남는다.
- 네트워크·호스트 로그. 공개 터널·Workers 는 더 남긴다.
- 암호를 아는 사람 + 서버 파일 = 읽힘. 암호를 메일/문자로 보내면 의미가 없다.
- Cloudflare Workers 만으로는 영구 저장이 안 된다. 새 KV/D1 을 열지 않는 한 본집은 로컬 파일.
- 옆자리, 악성코드, 화면공유는 이 방이 막지 못한다.

## 자리 만들기

1. 로컬에서 `npm run dev:hai-ic`
2. `/rooms` 에서 나와 그양반 암호를 한 번 심는다 (10자 이상).
3. 다른 기기는 그 호스트 주소로 들어와 같은 자리를 연다.

환경 변수로 잠글 수도 있다 (`PRIVATE_ROOMS_OWNER_PASS`, `PRIVATE_ROOMS_EM_PASS`). 값은 채팅에 넣지 말 것.
