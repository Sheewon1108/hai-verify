# HAI Verify — 한 장 요약 (학습용)

**Human-Heart + AI-Law = Verification** · **Created by KARAM SHIN**

---

## 1. 이게 뭔가

| | |
|---|---|
| **정의** | 사람이 주도하는 AI 검증 시스템 (human-led AI verification) |
| **만든 이유** | 실제 **사람–AI 상호작용 리스크** 경험에서 출발 |
| **목표** | 인간 판단을 **대체하지 않음** → **보호**함 |

---

## 2. 한 줄 원칙 (4단)

```
AI answers.     → AI가 답한다
HAI verifies.   → HAI가 검증한다
Human approves. → 사람이 승인한다
XGOMA executes. → XGOMA가 실행한다
```

**흐름:** Human → AI → HAI Verification → Human Approval → XGOMA

---

## 3. 제품이 하는 일 (4가지 반응)

| 상황 | HAI Verify |
|------|------------|
| 명백히 거짓 | **거짓**이라고 말함 |
| 위험함 | **위험**하다고 말함 |
| 불확실함 | **검증 필요**라고 말함 |
| 돈·법·의료·가족·보안·고위험 행동 | **사람 확인 필수** |

---

## 4. 반드시 기억할 문장

> **HAI Verify는 최종 결정을 내리지 않는다.**  
> 리스크를 감지하고, 불확실성을 설명하고, **행동 전에 사람의 검증을 요구한다.**

---

## 5. 학습 체크 (보여주며 물어볼 것)

1. AI 답변만으로 실행하면 안 되는 이유는? → **리스크·환각·과신** 가능  
2. HAI Verify의 역할은? → **판단 대체 X**, **위험·불확실성 표시 + 사람 확인**  
3. 누가 최종 승인? → **Human** (그 다음 XGOMA 실행)  
4. 의료·법률·금전 등은? → **무조건 human confirmation**

---

## 6. 하지 않는 말 (과장 금지)

- 특정 회사·파트너·AI 업체의 **승인·공식 인증**을 주장하지 않음  
- HAI Verify = **보조 검증 레이어**, 최종 책임은 **사람**
