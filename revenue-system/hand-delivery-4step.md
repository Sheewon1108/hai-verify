## 흐름 (한 줄)

받는다 → 검증한다 → 리포트 쓴다 → 보낸다. 끝.

---

## ① 받는다 — 입력

- 고객이 AI 결과물을 보냄 (카톡/메일/파일 아무거나, 최대 10건)
- 접수 확인 한 줄:

```
받았습니다. [날짜]까지 리포트 드립니다.
```

## ② 검증한다 — KARAM 작업 (건당 체크 4개)

| 체크 | 질문 |
|------|------|
| 사실 확인 | 수치·이름·날짜가 실제와 맞는가 |
| 근거 확인 | 출처 없는 주장이 있는가 |
| 과장 확인 | "최고", "보장", "100%" 같은 위험 표현이 있는가 |
| 법 리스크 | 의료·금융·법률 단정 표현이 있는가 (Law 축) |

