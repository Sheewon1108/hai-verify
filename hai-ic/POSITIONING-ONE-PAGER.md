# HAI-IC External Positioning One-Pager

## What it is

HAI-IC is an Intent Confidence gate for AI workflows.

Before AI answers or acts, HAI-IC measures whether the human intent is clear enough. It returns a 0-100 Intent Confidence score, turns Sincere Mode on only at 75%+, and keeps final responsibility with a human.

## Who it is for

Teams using AI for actions that can affect customers, money, reputation, safety, family decisions, or public claims.

Best first pilots:

- AI support or operations workflows
- Agent systems that call tools or trigger tasks
- Internal review queues where unclear intent creates risk
- Founder-led teams that need a simple human approval gate before AI action

## What the pilot proves

Objective pilot outputs only:

1. Number of requests analyzed
2. Number and percent of Sincere Mode ON requests
3. Number and percent of Sincere Mode OFF requests
4. p50 and p95 API latency
5. Processing speed in requests per second
6. Uptime against a 99.9% target
7. Cost reduction vs agreed baseline, if baseline cost is provided

If a number is not measured, it stays marked "not measured yet."

## Current proof

Measured Trust Ledger:

- 200 questions analyzed
- 82 Sincere Mode ON
- 118 Sincere Mode OFF
- 126 due-diligence questions
- 115 due-diligence questions blocked
- 75.8% average Intent Confidence

Real cash collected is not measured in this repo yet. Do not claim collected revenue until receipt evidence is verified.

## Pilot path

1. Buyer sends 20-50 real AI requests or agent tasks.
2. KARAM runs HAI-IC and exports the Trust Ledger.
3. Buyer reviews ON/OFF decisions, clarifying questions, and latency numbers.
4. KARAM and buyer decide Yes/No on a paid pilot.
